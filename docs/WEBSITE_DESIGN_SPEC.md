# Research Lab Website — Design & UI Specification

## 1. Purpose
Build a premium academic research-lab website rather than a conventional article/blog website.

The website should communicate:
- Research depth
- Technical credibility
- A clear scientific agenda
- Active projects, publications, people, and collaborators

## 2. Core Brand
- **Name**: KAIROS RESEARCH LAB
- **Positioning**: Models. Embodiment. Real-World Impact.
- **Primary Research Themes**:
  1. Time Series Models
  2. World Models
  3. Vision-Language-Action (VLA)
  4. Embodied AI
  5. Real-World AI

## 3. Visual Identity
- **Primary Background**: `#FAF8F5` (Warm Ivory)
- **Secondary Surface**: `#FFFFFF`
- **Highlight Surface**: `#FBF0EE` (Pale Rose)
- **Primary Accent**: `#B52E32` (Deep Muted Red)
- **Secondary Accent**: `#C94A4A`
- **Light Accent**: `#F3D9D7`
- **Text**: `#17191C`
- **Muted**: `#6D6A67`
- **Border**: `#E7E1DC`

Typography:
- **Display**: Instrument Serif / Georgia
- **UI / Body**: Inter / sans-serif
